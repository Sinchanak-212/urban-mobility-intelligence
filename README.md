# Urban Mobility Intelligence (UMI)

A Big Data Analytics project using Hadoop and Apache Spark to analyse
large-scale urban mobility data, discover transportation demand patterns,
identify geographic hotspots, detect anomalies, and forecast demand.

## Technology Stack

- Python
- Hadoop HDFS
- Apache Spark / PySpark
- Spark SQL
- FastAPI
- React + Vite
- Recharts
- React Leaflet

## Project Modules

1. Large-scale data processing
2. Transportation demand analytics
3. Geographic hotspot and route analysis
4. Travel behaviour analysis
5. Anomaly detection
6. Demand forecasting
7. Interactive dashboard

## Project Structure

- backend/ - Data processing, analytics and APIs
- frontend/ - Interactive dashboard
- data/ - Dataset storage
- docs/ - Project documentation
- scripts/ - Execution scripts
- tests/ - Testing

## Dataset

NYC TLC High Volume For-Hire Vehicle Trip Records.

Official source:
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

Large dataset files will be stored locally and will not be committed to Git.
